# Marketplace Agent Skills — «Инвестируй в мечту»

Скиллы задают поведение агента, независимые MCP дают данные и выполняют подтверждённые операции. Инвестконтур работает только в официальной песочнице Т‑Инвестиций.

| Тип | Компонент | Назначение |
| --- | --- | --- |
| Скилл | [Стилист](skills/wardrobe-stylist/SKILL.md) | Подбор образов, проверка вариантов и расчёт цены. |
| Скилл | [Копилка](skills/invest-in-dream/SKILL.md) | Предложение накопить, открытие цели, взнос и настройка сводки по согласию. |
| Скилл | [Дневная аналитика](skills/dream-daily-analysis/SKILL.md) | Прогресс целей, доступные деньги и следующий шаг. Ручной запуск или Hermes cron. |
| MCP | [Marketplace](mcp_servers/marketplace/README.md) | Живой каталог, варианты, наличие, цена и доставка; браузеры на удалённом хосте. |
| MCP | [Dream](mcp_servers/dream/README.md) | Связь цели со счётом, состояние и подтверждённые операции песочницы. |

## Сценарий

Агент подбирает образ через каталог. Если уместно, предлагает копилку и уточняет сумму и взносы. По отдельным подтверждениям Dream создаёт цель, открывает и проверяет счёт, затем сверяет виртуальный взнос. После «ставь» агент создаёт один штатный Hermes cron на владельца и приватный диалог. Короткий промпт задаёт поручение, прикреплённый скилл — методику. Джоб читает данные, но не торгует. Реального вывода и оплаты нет.

## Запуск и проверки

```bash
python3 scripts/install.py
python -m pip install -r requirements.txt -r mcp_servers/marketplace/requirements.txt 'httpx==0.28.1'
python scripts/validate.py
python scripts/check.py
python -m unittest discover -s mcp_servers/dream -p 'test_*.py'
PYTHONPATH=mcp_servers/marketplace python -m unittest discover -s mcp_servers/marketplace/tests
```

- Marketplace и Chromium запускаются на Linux-машине с проверенным доступом к нужным витринам. Hermes подключается по закрытому SSH-туннелю на loopback; для ручного входа в Ozon с телефона настраивается отдельный HTTPS viewer. См. README сервера.
- Dream запускается через `stdio` в изолированном профиле каждого участника; для cron используется отдельный экземпляр только на чтение. Не подключайте один профиль с одним ключом ко всем участникам.
- Переход со старой версии: обновите существующие задания под скилл аналитики. Прежние RPC предложения и рендера сводки удалены, записи целей не мигрируют. Секреты и профили храните вне репозитория.
