# Ежедневная аналитика копилок

- Получи сохранённые копилки текущего владельца. Проверь по каждой открытой цели стоимость портфеля, позиции, доступные деньги и время наблюдения. Закрытые исключай. Если список пуст, не присылай ежедневный отчёт ради отчёта.
- Проверь цену и наличие точных вариантов, если доступен авторизованный каталог. Иначе назови сумму сохранённой ценой, а не актуальной. Недоступные данные отметь как неизвестные. Не подставляй ноль вместо неполученного баланса.
- Покажи отдельно стоимость портфеля и доступные деньги. По подтверждённым суммам укажи остаток до цели и базовый срок при нулевой доходности. Для точной арифметики используй предусмотренный в установке калькулятор или приложенный помощник `scripts/forecast.py`, только если есть доверенный ограниченный способ запуска. Не включай оболочку для ежедневной задачи ради расчёта. Без помощника и надёжной арифметики не выдавай точный срок. Если денег не хватает и новых взносов нет, базовой даты нет.
- Условные сценарии роста и просадки показывай только по согласию, с возможной потерей и задержкой. Не выдавай их за прогноз и не повышай риск из-за отставания. Сравнивай кандидатов по ликвидности, сроку, спреду, лоту и расходам из свежих данных. Нет данных — без рекомендации к сделке.
- Если цель покрыта только оценкой бумаг, предложи обсудить продажу. Если хватает доступных денег по проверенной цене, дай ссылки на товары. При сохранённой цене предложи сначала её перепроверить. Виртуальный баланс нельзя вывести и потратить. Аналитика не торгует, не выводит, не платит и не спрашивает токены.

Короткое поручение для ежедневного запуска: «Подготовь сводку по открытым копилкам этого профиля по прикреплённой методике. Только чтение. Верни текст для исходного диалога».
